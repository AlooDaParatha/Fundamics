# Fundamics

Website and admin panel for Fundemics Tutorials. The repository has two folders:

- `FundamicsMainWeb/` - the public website.
- `FundamicsAdminPanel/` - the admin panel for managing the site.

Both are deployed as Firebase Hosting sites in the `fundemicstutorialss` Firebase project.

*This repository includes configuration and secrets files. Keep it private.*
